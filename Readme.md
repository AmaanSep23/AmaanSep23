## 🔭 What I'm Working On

**🧪 M.Tech Thesis: Consatrained Optimization of Mechanical Structures using PINN**
- Building a **PINN-based surrogate model** that minimizes the mass of a 3D mechanical structure while keeping its natural frequencies within a target range.
- Validated a 3D PINN on simple geometries (Cube, L-Bracket) : **error < 1%**.
- Stack: PyTorch, NVIDIA PhysicsNeMo, DeepXDE, ANSYS (APDL scripting), MATLAB.
